# 雅思口语教练 IELTS Speaking Coach（暂定名）

> **一个把你"扔进全英文环境"的桌面雅思口语教练：每天逼你开口，卡住时牵着你说下去，把你说的每句话沉淀成你自己的语料库。**

一个基于 AI 的桌面端雅思口语陪练产品（Windows），用"真人考官式"的语音对话帮你每天开口练口语，并在每次练习后给出雅思四项评分反馈。

---

## 为什么做这个产品

### 问题：雅思备考者的口语困境

中国考生备考雅思时，口语是普遍短板，但现有的练习方式各有致命伤：

| 现有方式 | 问题 |
|---|---|
| 找语伴/外教 | 难凑时间、贵、水平参差不齐 |
| 通用 AI 陪聊（如豆包、TalkAI） | 不针对雅思题型，无法按考试标准反馈 |
| 模考软件（雅思哥、BC 官方） | 还原考场，但只解决"考一次"，不解决"每天练" |
| 自己录音 | 没反馈、没人引导，坚持不下来 |

### 洞察：口语练习的核心不是"能聊"，而是"坚持"

通过自我访谈和竞品调研得出的三个关键洞察：

1. **没人逼，就坚持不下来** —— 需要"每日任务 + 打卡"的外部监督机制
2. **卡住时最需要的是"有人牵着说下去"** —— 而不是直接给答案
3. **说过的每句话都是资产** —— 自动沉淀成个人语料库，练习才不白费

### 竞品定位空白

市面上的 AI 口语产品（TalkAI 千万级用户、ELSA Speak、Speak 等）要么通用陪聊不针对雅思，要么只做发音训练，要么以手机为主。**在"雅思应试深度陪练 × 强迫输出机制 × 桌面端 × 按雅思四项评分的日常反馈"这个交叉点上，存在空白。**

## 产品定位

- **目标用户**：备考雅思、口语薄弱、缺乏自驱力的中国考生（第一用户 = 自己）
- **核心价值**：每天打开电脑就能"被逼着"开口，卡住有人救，练完有分数，说过的话都沉淀下来
- **差异化**：
  - 🎯 **雅思专项**：Part 1 真题题库按话题分类，考官按雅思规则提问（一次一问、不打断、不中途纠错）
  - 🧠 **教练记得你（Agent）**：弱点档案、历史得分、语料库都注入对话——开场就提起"上次你总是把 very like 说错"
  - 🗓️ **自主规划**：每天打开软件，教练决定今天练什么（最近 7 天最弱话题优先）+ 到期复习提醒
  - 🔧 **静默工具调用**：对话中教练悄悄查词典、存好表达、记错句、换下一题——你只感受到流畅的对话
  - 📢 **强迫输出**：全英文沉浸对话，每天完成任务才能打卡
  - 🆘 **三级卡住救援**：慢速重述问题 → 给关键词 → 给句子支架，牵着你说下去
  - 📊 **四项评分反馈**：每次练习按雅思标准（流利度/词汇/语法/发音）打分 + 纠错 + 新表达
  - 📚 **个人语料库**：错句、新表达自动收录，间隔重复复习（1→3→7→14 天）
  - 🖥️ **桌面端**：PC 学习场景，沉浸式无干扰

## 核心功能（v0.2 · Agent 版）

1. **每日口语任务（自主规划）**：规划器按"最近 7 天最弱话题优先"决定今天练什么，附到期复习清单
2. **回合制语音对话**：AI 考官语音提问 → 你开口回答 → 自动转写 → 考官追问/换题
3. **考官 Agent（记忆 + 工具）**：手写 ReAct 循环 + DeepSeek function calling——对话中静默查词典、收录好表达、记录错句、从题库取下一题；弱点档案与上次得分自动注入开场
4. **三级卡住救援**：随时输入 `h`，考官会慢速重述问题并给 3 个关键词
5. **雅思四项评分反馈**：练习结束自动生成流利度/词汇/语法/发音评分（0.5 分步进）+ 纠错 + 新表达 + 鼓励
6. **记忆沉淀**：错句入弱点档案、新表达入语料库、自动打卡；语料按 1→3→7→14 天间隔重复复习

**明确不做（当前）**：Part 2/3、发音打分、多语言、移动端、课程/外教——先把"每天逼你开口"这件事做透。

## 工作原理

```
你开口说话
    │  麦克风录音（sounddevice, 16kHz）
    ▼
语音识别 ASR ── faster-whisper 本地模型（免费，CPU 可跑）
    │  转写文本
    ▼
考官 Agent（手写 ReAct 循环）
    ├─ 记忆层 SQLite ── 弱点档案/历史得分/语料库，注入系统提示
    ├─ 工具调用 ── DeepSeek function calling：
    │    查词典 / 存好表达 / 记错句 / 取下一题（对考生完全隐形）
    └─ 大模型 ── deepseek-chat，按雅思 Part 1 规则生成追问/救援
    │
    ▼
语音合成 TTS ── edge-tts（免费，英音女声）
    │
    ▼
考官开口提问 → 循环…… → 练习结束 → 四项评分 → 记忆沉淀 + 打卡
```

一次完整练习的 API 成本约 ¥0.05（DeepSeek），ASR 和 TTS 完全免费。

## 技术选型

| 模块 | 选择 | 为什么 |
|---|---|---|
| 语言 | Python 3.12 | AI 生态最全、迭代快、易打包 |
| GUI | PySide6（Qt6） | 比 Electron 轻量，桌面体验好 |
| Agent | 手写 ReAct 循环 + function calling | 零框架依赖、行为可控、成本可测、逻辑透明 |
| 语音识别 | faster-whisper（本地 base 模型） | 免费、离线、隐私安全；接口抽象，可换云端 API |
| 大模型 | DeepSeek API（deepseek-chat） | 性价比极高，中文场景理解好，注册送体验金 |
| 语音合成 | edge-tts | 免费、音质自然（微软神经语音） |
| 录音/播放 | sounddevice + pygame | 简单可靠 |
| 存储 | SQLite | 弱点档案 + 语料库 + 打卡，零运维 |
| 打包 | PyInstaller（规划中） | 一键出 exe，用户免装环境 |

## 快速开始（Windows）

### 1. 准备

- Python 3.10+（本机实测 3.12.10）
- 一个 [DeepSeek API key](https://platform.deepseek.com)（注册送体验金，够练几百次）
- 麦克风和扬声器

### 2. 安装

```powershell
# 克隆仓库
git clone https://github.com/Johan535/ielts-speaking-coach.git
cd ielts-speaking-coach

# 创建虚拟环境并安装依赖
py -m venv .venv          # 若 py 启动器不可用，用完整路径：%LOCALAPPDATA%\Programs\Python\Python312\python.exe
.venv\Scripts\activate
pip install -r requirements.txt

# 配置 API key
copy config.example.json config.json
# 编辑 config.json，填入你的 api_key
```

> 注意：`av` 已固定为 13.1.0（新版 PyAV 与 faster-whisper 不兼容，踩坑记录见开发日志）。

### 3. 运行

```powershell
# 国内网络建议先设置模型镜像（首次运行需下载约 150MB 语音模型）
$env:HF_ENDPOINT = "https://hf-mirror.com"
python main.py
```

## 使用说明

### 图形界面（推荐）

```
python main.py --gui
```

1. 点「🚀 开始练习」：教练（Agent 规划器）告诉你今天练哪个话题、为什么（弱项优先）
2. AI 考官**出声**提问（英音女声）；对话中它会静默查词、收藏你的好表达、记录你的错句
3. 点「🎤 开始回答」开始录音 → 开口回答 → 再点一次「⏹ 结束回答」
4. 卡住时点「🆘 卡住了」：考官慢速重述 + 3 个关键词救援
5. 点「🏁 结束并评分」：自动生成**四项评分 + 纠错 + 新表达 + 鼓励**，并沉淀进弱点档案与语料库
6. 练完点「📚 复习到期表达」：间隔重复复习（1→3→7→14 天）

### 命令行

```
python main.py
```

流程相同：规划器选话题（打印理由+复习清单）→ 考官开场 → 回车录音 → `h` 救援 → `q` 结束 → 评分沉淀。

### 测试

- Agent 集成测试（无需麦克风，需 API）：`python agent_test.py` —— 记忆注入 → 规划 → 工具循环 → 评分沉淀全链路（21 项断言）
- GUI 冒烟测试（无窗口、不调 API）：`python gui_test.py`
- 语音链路冒烟测试：`python smoke_test.py`

## 常见问题

- **模型下载慢/失败**：设置 `$env:HF_ENDPOINT = "https://hf-mirror.com"` 后重试
- **录音没声音**：检查 Windows 麦克风权限与默认输入设备
- **语音合成失败**：edge-tts 需联网；失败时自动退化为纯文字提问
- **命令行中文乱码**：程序已强制 UTF-8 输出；如仍乱码请用 Windows Terminal
