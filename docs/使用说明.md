# 雅思口语教练 · 新用户快速上手

> AI 雅思口语陪练。考官**记得你**（弱点档案）、**会规划**（今天该练哪个话题）、**有工具**（悄悄查词、记录好表达）。

## 一、开始前：准备一个 DeepSeek API Key（约 2 分钟）

AI 对话按量计费，所以每人用自己的 key，互不干扰、各付各的（一次练习约几分钱）。

1. 打开 https://platform.deepseek.com 注册并登录
2. 左侧「API Keys」→「创建 API Key」→ 复制形如 `sk-xxxxxxxx` 的字符串（只显示一次，注意保存）
3. 在「充值」里充 10 元即可练很久

## 二、首次运行（约 1 分钟）

1. 双击 `IELTSCoach.exe`（Windows 可能提示"未知发布者"，点「更多信息」→「仍要运行」）
2. 程序会弹窗告诉你**配置文件已生成**，并自动打开该文件夹
3. 用记事本打开 `config.json`，把 `api_key` 后面的引号里填上你的 key，保存
4. 重新双击 `IELTSCoach.exe` 即可开始

## 三、怎么练

| 按钮 | 作用 |
|---|---|
| 🚀 开始练习 | 考官先告诉你**今天练什么话题、为什么**，然后开始提问 |
| 🎤 开始回答 / ⏹ 结束回答 | 按下开始说话，说完再按一下停止，自动转写成文字 |
| 🆘 卡住了 | 考官会慢速重述问题、给关键词提示，帮你继续说 |
| 🏁 结束并评分 | 结束本轮，给出雅思四项评分 + 纠错 + 值得记的表达 |
| 📚 语料库与复习 | 到期表达按记忆曲线复习（1→3→7→14 天），全部语料可标记掌握 |
| 🔥 打卡记录 | 连续练习天数 + 近 12 周热力图，每天一小格，坚持会变绿 |

## 四、常见问题

- **没声音**：考官说话靠语音合成（需联网），耳机没声检查系统默认输出设备
- **录音没反应**：Windows 设置 → 隐私 → 麦克风，允许桌面应用访问；检查默认输入设备
- **第一次转写很慢**：语音识别模型首次使用需下载约 150MB（一次性，之后离线可用）
- **提示"找不到配置文件"**：说明你的 `config.json` 还没填 key 或放错位置

## 五、数据在哪

你的练习记录、语料库、录音全部存在：`%APPDATA%\IELTSCoach`（资源管理器地址栏粘贴即可打开）。
不想用了直接删掉这个文件夹，等于清除全部数据。
